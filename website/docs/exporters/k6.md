# k6 — the native fit

k6 is the default renderer. It emits versioned, reviewable k6 scripts plus synthetic
payload pools: ramping-executor arrival profiles, request chaining with fail-fast
correlation, and cache-avoidance payload pools (Zipf-distributed keys with cache-hit-ratio
targeting). Open and closed arrival models both map natively. `synthetic=true` rides as
OTel baggage and span emission on every request. The V2a static gate runs `node --check`
(or `mcp-k6 validate_script` when available).

| | |
|---|---|
| **Arrival model** | open and closed, native |
| **Feeders / payloads** | pre-generated Zipf pools with cache-hit-ratio targeting |
| **`synthetic=true`** | OTel baggage + span emission per request |

See [`skills/k6-synthesis`](https://github.com/henrikrexed/AI-Performance-Testing/tree/main/skills/k6-synthesis)
and [How it works](../how-it-works/index.md) for where this sits in the loop.
